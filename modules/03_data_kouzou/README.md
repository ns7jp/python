## 1. 📘 この章で学ぶこと

この章では、Pythonの代表的な「データ構造(データを入れる入れ物の種類)」を学びます。

- **リスト(list)**: 複数の値を順番に並べて保存する、もっとも基本的な入れ物
- **辞書(dict)**: 「キー」と「値」の組み合わせでデータを保存する入れ物(例: サービス名 → ポート番号)
- **タプル(tuple)**: リストに似ているが、あとから中身を変更できない(変更しない)値の組
- **集合(set)**: 重複した値を持たない、順序のない入れ物。重複除去によく使う
- **リスト内包表記**: `[式 for 要素 in リスト if 条件]` という形で、リストを1行で作る書き方
- **in演算子**: ある値がリストや辞書、集合の中に含まれているかを調べる方法
- **sorted()とkey引数**: リストを並べ替える関数と、「何を基準に並べ替えるか」を指定する方法
- **スライス**: `リスト[開始:終了]` という形で、リストの一部分だけを取り出す方法

これらは、複数のサーバーやサービスの情報をまとめて管理・分析するための、
とても重要な道具です。

## 2. 🖥 サーバーエンジニアにとってなぜ重要か

サーバー構築エンジニア(インフラエンジニア)の仕事では、「1台のサーバー」だけでなく
「たくさんのサーバー・サービス・ログ」をまとめて扱う場面がほとんどです。この章で学ぶ
データ構造は、そうした情報を整理して扱うための土台になります。

- **サーバー一覧の管理**: 監視対象のサーバーが何十台、何百台とある場合、それぞれの
  名前・状態(稼働中/停止中)・IPアドレスなどをリストや辞書でまとめて管理します。
  「稼働中のサーバーだけを抜き出す」といった処理はリスト内包表記の得意分野です。
- **サービス名とポート番号の対応表**: 「SSHは22番、HTTPは80番、HTTPSは443番」
  といった対応関係は辞書(dict)で管理するのが自然です。設定ファイルの内容を
  読み込んで辞書にまとめ、後から素早く検索する、という使い方が定番です。
- **重複IPアドレスの除去**: アクセスログや接続履歴には、同じIPアドレスが何度も
  記録されていることがよくあります。集合(set)を使うと、重複のない
  「ユニークなアクセス元一覧」を簡単に作れます。
- **負荷順のソート**: 複数のサーバーのCPU使用率やアクセス数を見て、「負荷が高い順に
  上位5台だけ確認したい」という場面はとても多いです。`sorted()` の `key` 引数と
  スライスを組み合わせると、この処理を簡潔に書けます。

つまりこの章の内容は、**「複数の情報をどう整理して持つか」という、実務データを
扱う上での基本設計力**を養うものです。ここが身につくと、監視スクリプトや
設定管理ツールを書くときの見通しがぐっと良くなります。

## 3. 📖 解説

### 3.1 リスト(list)

リストは、複数の値を順番に並べて保存する入れ物です。角かっこ `[]` で作ります。

```python
server_names = ["web01", "web02", "db01"]

print(server_names[0])       # "web01" (最初の要素。添字は0から始まる)
print(len(server_names))     # 3 (要素数)

server_names.append("cache01")  # 末尾に要素を追加
print(server_names)             # ['web01', 'web02', 'db01', 'cache01']
```

### 3.2 辞書(dict)

辞書は「キー」と「値」の組み合わせでデータを保存する入れ物です。波かっこ `{}` を使い、
`{キー: 値}` という形で書きます。キーを指定すると、対応する値をすぐに取り出せます。

```python
service_ports = {"ssh": 22, "http": 80, "https": 443}

print(service_ports["http"])        # 80
print(service_ports.get("ftp"))     # None (存在しないキーでもエラーにならない)

service_ports["mysql"] = 3306       # 新しいキーと値を追加
```

`辞書名[キー]` は、キーが存在しないと `KeyError` というエラーになります。
存在しないかもしれないキーを安全に調べたいときは `.get()` メソッドを使うと、
見つからない場合に `None`(または指定したデフォルト値)を返してくれます。

### 3.3 タプル(tuple)

タプルはリストと似ていますが、丸かっこ `()` を使い、**一度作ったら中身を
変更できない(イミュータブル、と呼びます)** という特徴があります。
「サービス名とポート番号の組」のように、意味的にセットで扱いたい、かつ
あとから書き換える必要がないデータによく使われます。

```python
service = ("http", 80)
name, port = service   # タプルの中身を複数の変数に分解する(アンパック)
print(name)  # "http"
print(port)  # 80

# service[0] = "https"  # これはエラーになる(タプルは変更できない)
```

タプルのリストは、辞書を組み立てるための「材料」としてもよく使われます。

```python
pairs = [("ssh", 22), ("http", 80)]
port_map = {}
for name, port in pairs:
    port_map[name] = port
# port_map は {"ssh": 22, "http": 80} になる
```

### 3.4 集合(set)

集合(set)は「重複した値を持たない、順序のない入れ物」です。中かっこ `{}` を
使いますが、辞書と違って `キー: 値` ではなく値だけを並べます。

```python
ips = ["10.0.0.1", "10.0.0.2", "10.0.0.1", "10.0.0.3", "10.0.0.2"]
unique_ips = set(ips)
print(unique_ips)  # {'10.0.0.1', '10.0.0.2', '10.0.0.3'} (順序は保証されない、重複はなくなる)
```

集合は「順序がない」ため、並び順を揃えたい場合は `sorted()` と組み合わせて
リストに変換するのが定番の使い方です(このあとの3.6で説明します)。

```python
sorted_unique_ips = sorted(set(ips))
print(sorted_unique_ips)  # ['10.0.0.1', '10.0.0.2', '10.0.0.3'] (昇順のリストになる)
```

### 3.5 リスト内包表記

リスト内包表記(list comprehension)は、「リストの中から条件に合う要素を取り出して、
新しいリストを作る」という処理を1行で書ける、Pythonらしい書き方です。

```python
numbers = [1, 2, 3, 4, 5, 6]

# for文で書く場合
even_numbers = []
for n in numbers:
    if n % 2 == 0:
        even_numbers.append(n)

# リスト内包表記で書く場合(上と同じ結果になる)
even_numbers = [n for n in numbers if n % 2 == 0]
print(even_numbers)  # [2, 4, 6]
```

書式は `[式 for 要素 in 元のリスト if 条件]` です。`if 条件` の部分は省略することもできます
(その場合はすべての要素が対象になり、`式` の部分だけを使って新しいリストを作ります)。

```python
names = [s["name"] for s in servers if s["status"] == "active"]
# 「servers というリストの中から、statusが"active"の要素だけを対象に、
#  その要素の"name"を取り出して新しいリストを作る」という意味
```

### 3.6 in演算子

`in` 演算子は、「ある値がリストや辞書、集合の中に含まれているかどうか」を調べます。
結果は `True` か `False` の真偽値(bool)になります。

```python
allowed_ports = [22, 80, 443]
print(80 in allowed_ports)     # True
print(8080 in allowed_ports)   # False

service_ports = {"ssh": 22, "http": 80}
print("ssh" in service_ports)  # True (辞書に対してinを使うと「キーが存在するか」を調べる)
print(22 in service_ports)     # False (値の22ではなく、キーとして22があるかを調べている点に注意)
```

### 3.7 sorted()とkey引数

`sorted()` は、リストなどを並べ替えた**新しいリストを返す**組み込み関数です
(元のリスト自体は変更されません)。

```python
numbers = [5, 2, 8, 1]
print(sorted(numbers))              # [1, 2, 5, 8]  (昇順)
print(sorted(numbers, reverse=True))  # [8, 5, 2, 1]  (降順)
```

辞書のリストのように「何を基準に並べ替えるか」を指定したい場合は、`key` 引数に
「並べ替えの基準にしたい値を返す関数」を渡します。`lambda`(ラムダ)式という、
名前のない小さな関数を使うのが定番です。

```python
servers = [
    {"name": "web01", "cpu_load": 45.0},
    {"name": "web02", "cpu_load": 92.5},
]

# key引数に「サーバー1件(辞書)を受け取り、cpu_loadの値を返す関数」を渡す
sorted_servers = sorted(servers, key=lambda s: s["cpu_load"], reverse=True)
# cpu_loadが大きい順に並び替えられる
```

`lambda s: s["cpu_load"]` は「`s` という引数を受け取り、`s["cpu_load"]` を返す関数」を
その場で作る書き方です。`def` で普通の関数を定義してから `key=` に渡しても同じ結果になります。

### 3.8 スライス

スライスは `リスト[開始:終了]` という書き方で、リストの一部分だけを取り出す方法です。
「開始」のインデックス(添字)から「終了」のインデックスの**手前まで**を取り出します。

```python
values = [10, 20, 30, 40, 50]

print(values[0:2])   # [10, 20] (インデックス0から2の手前=1まで)
print(values[:3])    # [10, 20, 30] (開始を省略すると先頭から)
print(values[2:])    # [30, 40, 50] (終了を省略すると末尾まで)
print(values[:2])    # [10, 20] (「上位2件」を取り出したいときによく使う書き方)
```

`sorted()` と組み合わせると、「並べ替えてから上位N件だけ取り出す」という
実務でよくある処理を簡潔に書けます。

```python
top2 = sorted(servers, key=lambda s: s["cpu_load"], reverse=True)[:2]
```
