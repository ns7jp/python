## 1. 📘 この章で学ぶこと

この章では、Pythonの「制御構造(コントロールフロー)」と呼ばれる仕組みを学びます。
制御構造とは、プログラムの実行順序をコントロール(制御)する仕組みのことで、
具体的には次の内容を扱います。

- **条件分岐**: `if` / `elif` / `else` を使って「もし〇〇なら△△する」という処理を書く方法
- **forループ**: リストなどの要素を順番に処理する繰り返し処理と、`range()` を使った回数指定の繰り返し
- **whileループ**: 「条件が成り立っている間だけ」繰り返す処理
- **break / continue**: ループを途中で抜けたり、その回だけスキップしたりする方法
- **リストに対する集計処理**: for文を使ってリストの中身を数えたり、割合を計算したりする方法

これらはPythonに限らず、ほぼすべてのプログラミング言語に共通する超基本の考え方です。
ここをしっかり身につけると、この後の章(関数、ファイル操作、自動化スクリプトなど)が
ぐっと理解しやすくなります。

## 2. 🖥 サーバーエンジニアにとってなぜ重要か

サーバー構築エンジニア(インフラエンジニア)の仕事では、「条件に応じて処理を分ける」
「同じ処理を何度も繰り返す」という場面が本当にたくさん出てきます。いくつか例を挙げます。

- **ポート番号による分類**: サーバーが使っているポート番号を見て、「これはよく知られたサービス用のポートか」
  「アプリケーション用に割り当てられたポートか」を判断する場面があります。これは `if` / `elif` / `else`
  で条件分岐する処理そのものです。
- **複数サーバーのステータス確認ループ**: 監視対象のサーバーが10台、100台とある場合、1台ずつ手作業で
  確認するのは非現実的です。`for` ループで「サーバーのリストを順番にチェックする」処理を書けば、
  何台あっても同じコードで対応できます。
- **接続失敗時のリトライ処理**: ネットワークは一時的に不安定になることがあります。1回失敗しただけで
  諦めるのではなく、「〇回までは間隔をおいて再接続を試みる」という処理はとても実践的で、
  `while` ループとカウンタ、`break` の組み合わせでよく実装されます。
- **稼働率(アップタイム率)の計算**: 「このサーバーは直近100回のヘルスチェックのうち何%成功したか」
  といった指標は、監視ダッシュボードや障害対応の判断材料としてよく使われます。これは `for` ループで
  リストを集計する典型的な処理です。

つまりこの章で学ぶ内容は、**監視スクリプトや自動化ツールを作るための土台**になります。
「条件分岐」と「繰り返し」を使いこなせるようになると、日々の運用作業を自動化する第一歩を
踏み出せます。

## 3. 📖 解説

### 3.1 条件分岐: if / elif / else

`if` 文は「もし条件が成り立つなら、このブロックを実行する」という文法です。
複数の条件を順番にチェックしたいときは `elif`(else if の意味)を使い、
どの条件にも当てはまらなかった場合の処理は `else` に書きます。

```python
port = 8080

if port <= 1023:
    print("システムポートです")
elif port <= 49151:
    print("登録済みポートです")
else:
    print("動的ポートです")
```

ポイント:

- `if` は必ず1つ、`elif` は0個以上、`else` は0個または1個(必ず最後)という順番で書きます。
- 条件は上から順番にチェックされ、最初に成立した(条件が `True` になった)ブロックだけが
  実行されます。それ以降の `elif` / `else` はチェックされません。
- インデント(字下げ)がとても重要です。Pythonはインデントの深さでブロック(処理のまとまり)を
  判断する言語なので、スペースの数がずれるとエラーになったり、意図しない動作になったりします。

### 3.2 forループと range()

`for` 文は、リストや文字列など「複数の値をまとめて持つもの」から要素を1つずつ取り出して
処理を繰り返すときに使います。

```python
servers = ["server-01", "server-02", "server-03"]

for server in servers:
    print(f"{server} をチェックしています...")
```

「〇回繰り返したい」というように**回数を指定して繰り返したい**場合は `range()` 関数を使います。

```python
for i in range(5):
    # iは 0, 1, 2, 3, 4 の順番に変化する(5は含まれないことに注意!)
    print(f"{i + 1}回目の処理です")
```

`range(5)` は 0, 1, 2, 3, 4 という5個の数を順に生成します。「終わりの数は含まれない」という点は
初心者がつまずきやすいポイントなので、覚えておきましょう。

### 3.3 whileループ

`while` 文は「条件が `True` である間だけ」処理を繰り返します。繰り返す回数があらかじめ
決まっていない場合(例:「成功するまで」「上限に達するまで」)によく使われます。

```python
attempt = 0
max_retries = 3

while attempt < max_retries:
    print(f"{attempt + 1}回目の接続を試みます")
    attempt += 1  # カウンタを更新し忘れると無限ループになるので要注意!
```

**注意**: `while` ループでは、ループの中でカウンタや条件に関わる変数を必ず更新してください。
更新を忘れると条件が永遠に `True` のままになり、プログラムが終わらなくなる「無限ループ」に
陥ってしまいます。

### 3.4 break と continue

- `break`: ループを**即座に終了**します。「もう繰り返す必要がなくなった」ときに使います
  (例: 接続に成功したので、これ以上リトライする必要がない)。
- `continue`: 現在の回の残りの処理を**スキップして次の周回に進みます**。ループ自体は終わりません
  (例: エラーのデータだけスキップして、次のデータの処理に進みたい)。

```python
for status in ["ok", "error", "ok", "critical", "ok"]:
    if status == "critical":
        print("致命的なエラーを検知したため、処理を中断します")
        break
    if status == "error":
        print("エラーが発生しましたが、処理を継続します(このデータはスキップ)")
        continue
    print(f"ステータス: {status} (正常に処理しました)")
```

### 3.5 リストに対する集計処理

`for` 文と `if` 文を組み合わせると、リストの中身を数えたり、条件に合う要素だけをカウントしたり
できます。

```python
statuses = ["ok", "ok", "error", "ok"]
ok_count = 0

for status in statuses:
    if status == "ok":
        ok_count += 1

print(f"正常なサーバー: {ok_count}台")
```

この「forでリストを回しながら、if条件に合うものだけカウントする」というパターンは非常によく
使うので、体に染み込ませておくと後々とても役立ちます。

## 4. 💻 サンプルコードの説明

`examples/example.py` には、この章で学んだ内容をまとめて動かせるサンプルコードが入っています。
以下のコマンドで実行できます(リポジトリのルートディレクトリで実行してください)。

```bash

```

サンプルコードは4つのセクションに分かれています。

1. **`section1_if_elif_else()`**: ポート番号のリストを1つずつチェックし、`if`/`elif`/`else` で
   「システムポート」「登録済みポート」「動的ポート」「無効なポート」に分類して表示します。
2. **`section2_for_and_range()`**: `range()` を使って5台分のサーバーを順番にチェックするループの例です。
   あらかじめ用意した疑似的なチェック結果(ダミーデータ)を使い、正常台数・異常台数を集計します。
3. **`section3_while_break_continue()`**: `while` 文とカウンタ変数を使い、接続が成功するまで
   リトライを繰り返す処理をシミュレーションします。成功したら `break` でループを抜ける様子や、
   `while ... else` の使い方(ループが `break` されずに終わったときだけ実行される)も確認できます。
4. **`section4_aggregation()`**: 直近10回分のヘルスチェック結果(成功/失敗のリスト)を `for` 文で
   集計し、稼働率(%)を計算して表示します。

**外部ネットワークへのアクセスは一切行いません。** すべてコードの中に用意したダミーデータ
(疑似的なサーバーの状態やチェック結果)を使ってシミュレーションしているので、安心して
何度でも実行してみてください。コードを少し書き換えて(例: ダミーデータの中身を変えて)、
出力がどう変わるかを確かめてみるのもおすすめの学習方法です。

  稼働率(%)を計算します。

  - 稼働率(%)の計算式は「成功回数 ÷ 全体の回数 × 100」です。
