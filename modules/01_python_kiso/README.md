## 1. 📘 この章で学ぶこと

この章では、次のことを学びます。

- **変数**: データに名前をつけて保存する箱のようなしくみ
- **基本データ型**: `int`(整数)、`float`(小数)、`str`(文字列)、`bool`(真偽値)
- **型変換**: `int()` / `float()` / `str()` を使ってデータ型を変える方法
- **演算子**: 算術演算子(`+ - * / // % **`)、比較演算子(`== != > < >= <=`)、論理演算子(`and or not`)
- **f-string**: 文字列の中に変数の値を埋め込んで、見やすい文章を作る方法
- **`round()`**: 小数を指定した桁数で丸める方法

これらはPythonのすべての土台になる知識です。この章をしっかりマスターすれば、この後の章(条件分岐やループ、ファイル操作など)がぐっと理解しやすくなります。

## 2. 🖥 サーバーエンジニアにとってなぜ重要か

「変数」や「演算子」なんて、サーバー運用の仕事とどう関係あるの? と思うかもしれません。実は、サーバー運用の現場では、この章で学ぶ基本の計算・文字列整形を **毎日のように** 使います。

- **ディスク使用率の計算**: 「使用容量 ÷ 総容量 × 100」という算術演算で、ディスクの空き容量が危険な水準かどうかをチェックします。
- **メモリ使用率の監視**: サーバーのメモリがどれくらい使われているかをパーセントで表示し、閾値(しきい値。基準となる数値のこと)を超えたら警告を出す、といった処理を書きます。
- **稼働時間(uptime)の表示**: サーバーが起動してから何秒経過したかを、人間が読みやすい「◯日◯時間◯分◯秒」という形式に変換します。

- **わかりやすいログ・通知メッセージ**: f-stringを使って「警告: メモリ使用率が90.00%です」のような、人間にとって読みやすいメッセージを作ります。

つまり、この章で学ぶ内容は、監視スクリプトや自動化ツールを自作するときの「一番最初に必要になる基礎体力」です。ここでしっかり練習しておくと、後々の章がとても楽になります。

## 3. 📖 解説

### 3.1 変数(へんすう)とは

変数とは、値(データ)に名前をつけて保存しておく「箱」のようなものです。

```python
disk_used_gb = 45.5   # 使用中のディスク容量(GB)
disk_total_gb = 100   # ディスクの総容量(GB)
server_name = "web01" # サーバー名
```

Pythonでは `変数名 = 値` という形で変数に値を代入(だいにゅう。値を入れること)します。変数名はあとで見返してもわかりやすい名前にするのが大切です(`x` より `disk_used_gb` の方が意味が伝わりますね)。

### 3.2 基本データ型

Pythonの代表的なデータ型は次の4つです。

| データ型 | 意味 | 例 |
|---|---|---|
| `int` | 整数(せいすう) | `100`, `-5`, `0` |
| `float` | 小数(しょうすう) | `3.14`, `45.5`, `0.0` |
| `str` | 文字列(もじれつ) | `"web01"`, `"OK"` |
| `bool` | 真偽値(しんぎち。True/Falseのどちらか) | `True`, `False` |

変数の型は `type()` 関数で確認できます。

```python
print(type(100))     # <class 'int'>
print(type(3.14))    # <class 'float'>
print(type("web01")) # <class 'str'>
print(type(True))    # <class 'bool'>
```

**注意点**: Pythonでは `bool` は実は `int` の仲間(専門的には「サブクラス」)で、`True` は `1`、`False` は `0` として扱われます。ただし、意味としては「整数」と「真偽値」は別物として扱うのが自然です。この章の演習でもこの違いを意識する場面があります。

### 3.3 型変換

型変換とは、あるデータ型を別のデータ型に変えることです。サーバー運用では、設定ファイルやコマンドの出力から読み取った「文字列」を「数値」に変換して計算する、という場面がとてもよく出てきます。

```python
port_str = "8080"
port_num = int(port_str)   # 文字列 "8080" を 整数 8080 に変換
print(port_num + 1)        # 8081

usage_str = "45.5"
usage_num = float(usage_str)  # 文字列を小数に変換
print(usage_num * 2)          # 91.0

count = 3
count_str = str(count)        # 整数を文字列に変換
print("使用中: " + count_str + "台")
```

- `int()`: 文字列や小数を整数に変換します(例: `int("10")` → `10`、`int(3.9)` → `3` (切り捨て))
- `float()`: 文字列や整数を小数に変換します(例: `float("3.14")` → `3.14`)
- `str()`: 数値などを文字列に変換します(例: `str(100)` → `"100"`)

型変換できない文字列(例: `int("abc")`)を変換しようとすると `ValueError` というエラーが発生します。エラーへの本格的な対処(例外処理)は別の章で学びますが、「変換できないこともある」ということは覚えておきましょう。

### 3.4 算術演算子

数値の計算に使う演算子です。

| 演算子 | 意味 | 例 | 結果 |
|---|---|---|---|
| `+` | 足し算 | `5 + 3` | `8` |
| `-` | 引き算 | `5 - 3` | `2` |
| `*` | かけ算 | `5 * 3` | `15` |
| `/` | 割り算(常にfloatになる) | `5 / 2` | `2.5` |
| `//` | 整数除算(切り捨て除算) | `5 // 2` | `2` |
| `%` | 余り(剰余) | `5 % 2` | `1` |
| `**` | べき乗 | `2 ** 3` | `8` |

サーバー運用では、`/` を使ったパーセント計算(例: `使用量 / 総量 * 100`)や、`%` を使った「n個ごとに処理する」といった判定によく使われます。

### 3.5 比較演算子と論理演算子

比較演算子は2つの値を比べて `True` か `False` を返します。

| 演算子 | 意味 |
|---|---|
| `==` | 等しい |
| `!=` | 等しくない |
| `>` | より大きい |
| `<` | より小さい |
| `>=` | 以上 |
| `<=` | 以下 |

論理演算子は、複数の条件を組み合わせるときに使います。

| 演算子 | 意味 | 例 |
|---|---|---|
| `and` | かつ(両方True) | `(port >= 0) and (port <= 65535)` |
| `or` | または(どちらかTrue) | `(status == "OK") or (status == "WARN")` |
| `not` | 否定(Trueなら反転) | `not is_full` |

例えば「メモリ使用率が80%を超えたら警告」という判定は `usage_percent > 80` という比較演算で表現できます。

### 3.6 f-stringによる文字列整形

f-string(エフストリング)は、文字列の中に `{}` を使って変数の値を埋め込める、とても便利な書き方です。文字列の前に `f` をつけるのが特徴です。

```python
server_name = "web01"
usage_percent = 72.567

message = f"{server_name} のディスク使用率は {usage_percent:.2f}% です"
print(message)  # web01 のディスク使用率は 72.57% です
```

`{usage_percent:.2f}` の `:.2f` は「小数点第2位まで表示する」という書式指定です(`f` は float=小数を意味します)。サーバーの監視メッセージやログを作るときに非常によく使う書き方なので、ここでしっかり慣れておきましょう。

### 3.7 `round()` による丸め処理

`round(数値, 桁数)` を使うと、指定した桁数で数値を丸める(概数にする)ことができます。

```python
print(round(3.14159, 2))  # 3.14
print(round(45.555, 2))   # 45.55 や 45.56 になる場合がある(後述の注意点を参照)
print(round(45.0))        # 45 (桁数を省略すると整数に丸める)
```

**注意点**: `round()` はコンピュータ内部での小数の表現(浮動小数点数)の都合上、人間の感覚とわずかに異なる丸め方(「銀行丸め」と呼ばれる方式)になることがあります。厳密な金額計算などでは注意が必要な話題ですが、この章では「小数点第2位までに丸める」という基本的な使い方を押さえれば十分です。

## 5. ✍️ 演習問題(各演習の目的・ヒント・難易度)

演習は `exercises/` フォルダの中にある関数を実装する形式です。それぞれの関数には日本語のdocstring(関数の説明文)がついているので、まずはそれをよく読みましょう。

### 演習1: `exercises/exercise1.py` (難易度: ★☆☆)

**目的**: 算術演算子・`round()`・f-stringの基本を身につける。

- `calc_disk_usage_percent(used_gb, total_gb)`: ディスクの使用容量と総容量からディスク使用率(%)を計算し、小数点第2位までround()した数値(float)を返す関数です。`total_gb` が0の場合は0.0を返してください(0での割り算はエラーになるため、事前にチェックが必要です)。
- `format_percent(percent)`: 数値を受け取り、`"12.34%"` のような文字列に整形して返す関数です。f-stringの書式指定 `:.2f` を使いましょう。

**ヒント**: 使用率は「使用量 ÷ 総量 × 100」で計算できます。`round(値, 2)` で小数点第2位まで丸められます。`total_gb` が0のときの特別扱いを忘れずに。

### 演習2: `exercises/exercise2.py` (難易度: ★☆☆)

**目的**: 整数除算(`//`)・剰余(`%`)・f-stringを組み合わせて、人間が読みやすい時間表記を作る。

- `seconds_to_hms(total_seconds)`: 経過秒数(サーバーのuptimeを想定)を受け取り、「1日2時間3分4秒」のような日本語の文字列を返す関数です。0日の場合は日の部分を省略して「2時間3分4秒」のように表示します。

**ヒント**: `total_seconds // 86400` で日数、余りをさらに `// 3600` すると時間、というように、`//`(整数除算)と `%`(剰余)を順番に使って分解していきます。1日 = 86400秒、1時間 = 3600秒、1分 = 60秒です。

### 演習3: `exercises/exercise3.py` (難易度: ★★☆)

**目的**: 型チェック・比較演算子・論理演算子を使って、入力値の妥当性を検証する。

- `is_valid_port(port)`: 引数がポート番号として妥当か(0以上65535以下の**整数**であるか)を判定してTrue/Falseを返す関数です。文字列(`"8080"`)や小数(`8080.0`)が渡された場合はFalseを返す必要があります。つまり「値の範囲」だけでなく「型そのもの」もチェックする必要があります。

**ヒント**: `isinstance(値, int)` で型を確認できます。ただし、Pythonでは `bool` 型(`True`/`False`)も `int` の仲間として扱われてしまう(`isinstance(True, int)` は `True` になる)ため、`True`/`False` が渡された場合の扱いにも注意してdocstringを読んでください。

### 演習4: `exercises/exercise4.py` (応用, 難易度: ★★★)

**目的**: これまでの知識(算術演算子・比較演算子・f-string)を組み合わせて、実務に近い「監視メッセージ生成」を実装する。

- `memory_alert_message(used_mb, total_mb, threshold_percent=80.0)`: メモリ使用率を計算し、閾値(デフォルトは80%)を超えていたら警告メッセージ、超えていなければ正常メッセージを、それぞれ決まった文言のf-stringで返す関数です。

**ヒント**: 使用率の計算方法は演習1と同じです。「超えている」かどうかは `>` を使います(閾値ちょうどの場合は正常とみなします)。戻り値の文言は `solutions/exercise4.py` やテストコード(`tests/test_exercise4.py`)を参考にすると、期待される文字列の形式が正確にわかります。
